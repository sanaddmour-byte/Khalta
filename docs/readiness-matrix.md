# Readiness matrix — as of 2026-10-04

Five separate questions for every capability, never merged into one "ready" word:

- **Built** — the code exists and runs.
- **Tested** — an automated test proves it (the file is named). Tests use SYNTHETIC data and synthetic engineering values.
- **Reviewed by a person** — a human has checked it against the real procedure. **Nothing here has been, except where stated.**
- **Needs engineering input** — a value or decision only QC / a qualified engineer can supply. The app blocks until it is entered; none is invented.
- **Needs integration / operations** — something outside the code (a live service, a channel, a drill).
