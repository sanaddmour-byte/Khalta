# Appendices

## Appendix A — Seed YAML format

One file per topic, e.g. `packages/rules/seeds/aci/durability.yaml`:

```yaml
ruleset: ACI
edition: "ACI 318-19"
source_doc: "ACI 318-19 Building Code Requirements for Structural Concrete"
rules:
  - key: durability.S2.max_wcm
    kind: limit_max            # limit_max | limit_min | allowed_set | prohibition |
                               # range | tolerance | table | value | info | parameter
    requirement_class: CODE_HARD
    applies_to: { exposure: [S2] }
    prerequisites: []
    value: 0.45
    units: ratio
    clause_ref: "ACI 318-19 Table 19.3.2.1"
    verified: false
    note_en: "Max w/cm for sulfate exposure S2"
    note_ar: "أقصى نسبة ماء إلى مواد إسمنتية لفئة التعرض S2"
  - key: prop.water.non_ae
    kind: table
    requirement_class: DESIGN_AID
    applies_to: { air_entrained: false }
    rows: { name: slump_mm, values: [[25, 50], [75, 100], [150, 175]] }
    cols: { name: nmas_mm, values: [9.5, 12.5, 19, 25, 37.5, 50] }
    data:
      - [207, 199, 190, 179, 166, 154]
      - [228, 216, 205, 193, 181, 169]
      - [243, 228, 216, 202, 190, 178]
    units: kg/m3
    interpolation: linear
    clause_ref: "ACI 211.1 Table 6.3.3"
    verified: false
```

Design-aid tables use `requirement_class: DESIGN_AID`; they feed `MODEL_BASELINE` evidence, never compliance. JS skeleton entries use `value: null`, `clause_ref: "JSC-2022 §TBD"`, or `inherits: "ACI:<key>"`.

## Appendix B — Fixture formats

`packages/engine/test/fixtures/<id>.json`, validated by `fixture.schema.json`. Two modes:

**Evaluate fixture (M2.1)** — given proportions, expected recomputed results:

```json
{
  "id": "amm01-c30-legacy",
  "mode": "evaluate",
  "source": "Approved design AMM01-C30 (2025), entered by Sanad",
  "ruleset_mode": "ACI",
  "request": {
    "fc_mpa": 30, "basis": "cylinder", "exposure": ["F0", "S0", "W0", "C1"],
    "slump_mm": 125, "nmas_mm": 19, "pumpable": true
  },
  "materials": [
    { "id": "cem1", "category": "cement", "sg": 3.15, "c3a_pct": 7.5, "price_jod_per_kg": 0.075 },
    { "id": "foul", "category": "coarse_agg", "sg_ssd": 2.65, "absorption_pct": 1.2,
      "passing_pct": { "25": 100, "19": 95, "12.5": 40, "9.5": 15, "4.75": 3 },
      "price_jod_per_kg": 0.007 }
  ],
  "proportions_kg_per_m3": { "cem1": 360, "water": 175, "foul": 610 },
  "expected": {
    "wcm": 0.486, "volume_m3": 1.000, "cost_jod_per_m3": null,
    "compliance": { "durability.C1.max_cl": "pass" },
    "tolerance": { "volume": 0.002, "wcm": 0.001, "cost": 0.001 }
  }
}
```

**Design fixture (M3.1)** — same structure with `"mode": "design"`, a `config` block (cement, SCM, SCM %, admixture, dosage level) and `expected.kg_per_m3` with tolerances (cement ± 3, water ± 3, aggregates ± 10, volume ± 0.002).

All values above illustrate the format only — they are not a real design, and the example proportions are deliberately incomplete.

## Appendix C — Demo dataset (synthetic, deterministic)

Generated by `packages/db/seeds/demo/generate.ts` with a fixed random seed, labelled **SYNTHETIC** wherever it appears.

- 2 plants: AMM-01 (Amman), AQB-01 (Aqaba).
- Cements: CEM I 42.5N, CEM I 42.5N-SR3, CEM II/A-P 42.5N (with c3a_pct); 1 natural pozzolan SCM.
- 6 aggregates per plant (رمل، ناعمة، سمسمية، عدسية، فولية، حمصية) from different sources, with full tests; one expired test.
- 2 admixtures: Type F superplasticizer and Type D retarder, each with a 4-point dosage → water-reduction table.
- Full price matrix with different prices per plant, one stale cell, one material unpriced at AQB-01; two price snapshots.
- 3 legacy designs per plant (two attested, one awaiting attestation); 6 months of synthetic volumes.
- 60 strength results per plant across 3 w/cm levels, including one low-strength sequence that triggers an acceptance alert.
- Designs in every lifecycle state, so the UI quality gate never screenshots an empty state by accident.
